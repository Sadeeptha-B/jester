# Jester

A living little world of autonomous absurdity. See [docs/brief.md](docs/brief.md).

```sh
npm install
npm run dev        # the kingdom, on http://localhost:5173
npm test           # simulation tests
npm run build      # typecheck and production build
```

In development, `/props.html` shows every baked asset, and the main page takes
`?seed=7&hour=19&weather=rain&speed=20&nocurtain`.
